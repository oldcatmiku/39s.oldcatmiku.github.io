Software

Obsidian 笔记软件
Obsidian 鼓励你带着思考书写。相比纸质笔记，它方便反复修改和查找保存。
你可以在这里下载：obsidian.md

AdGuard 广告拦截器
关闭任何学习网站的广告。很有必要。
官网 或者 Chrome 插件

w3schools
学习 C、Python，或者任何编程语言。
英文页面（搭配网页翻译使用）www.w3schools.com
中文页面 w3schools.org.cn
广告似乎很多，用上面那个屏蔽就好。

学习通挂课
自动挂完课程，自动 ai 答题。
github 地址：github.com/unraous/uxuescript
扫码登录就可以直接挂课了。配置 ai 答题你可以输入 Api key。如果不知道，可以去搜索 deepseek 一类 ai 如何获取 key。
晚上睡觉时把电脑设置成“盖下笔记本盖不执行任何操作”，这样可以通宵挂课。

Study Ways

●　我很建议遇到不知道的问题去搜索引擎。使用 Bing 而不是百度。或者，把整段话复制下来问 ai。最后再尝试请教别人。

●　学习编程语言的有趣的方法是，写好一个标准程序之后，加入你脑中胡思乱想的、任何花里胡哨的东西。然后为它实现功能。这相比一直做练习题会更有趣，也不会枯燥。比如把“猜数字”里的提示变得莫名其妙，等等。
